# 기존 실험 보존

python/은 2026-11-09까지의 참조 구현·프롬프트·Schema·결과 문서 스냅샷이다. Spring 이식에는 상위 README의 *.spring-v1 파일을 사용한다.
기존 원본 자막·영상 설명란·전체 실험 원문은 로컬 ai/samples, ai/runs, ai/results에 그대로 보존했다. 공개 레포에는 제3자 자막·실제 사용자 대화·키를 복사하지 않는다.
기존 공개용 가상 질문과 오프라인 코드는 포함했다. 이전 모델 호출 결과를 Spring 계약용 버전의 품질 점수로 합산하지 않는다.

이전 기록: 영상7개×3회 첫 시도0/21 실패, 원문 일치97%(모델 채점), 실제42분 분석·합성60분 입력, 채팅12건 스트리밍 통과. 이는 구간 밖 상세 근거를 경고로 통과시키던 이전 실험 형식이며 현재 Spring의 엄격한 구간 검증과 다르다.

코드가 참조하는 samples/runs/gate_set 등 실제 영상 자료는 공개 번들에서 제외했으므로 해당 데이터 의존 실험은 원본 보유자의 로컬에서만 재현 가능하다. 새 handoff/examples는 모두 직접 작성한 가상 자료로 독립 재현 가능하다.
