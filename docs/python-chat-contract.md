# Python 채팅 계약 — 이전 설계 기록

현재 실행 경로는 **Spring Chat의 GPT 직접 호출**이다. 현행 입력·출력·모델 설정·스트리밍 규칙은 [직접 생성 계약](chat-generation-contract.md)을 따른다.

이전 Python HTTP2.0의 원문은 [4ab3ffe 시점 문서](https://github.com/AnGyeongKK/ITip-server/blob/4ab3ffe/docs/python-chat-contract.md)에 보존한다. 이 HTTP 버전은 현재 모델 출력 Schema의 버전을 뜻하지 않는다.
